# Sanjit & Sanchita ✨ The Close Friend Chronicles

A cute, modern, and interactive digital space celebrating the friendship, coffee rituals, marathon phone calls, and memories of Sanjit & Sanchita.

## 🌸 Features
- **⚡ Friendship Vibe Radar**: Telemetry & compatibility dynamics.
- **🎒 The Starter Pack**: Shared inside jokes and hangout rituals.
- **📸 Digital Scrapbook**: Flippable polaroid postcards with custom filters (*Natural, Warm, Vintage, Dreamy, Mono*).
- **📖 Friendship Odyssey Timeline**: 5-phase story from the Shaadi.com meeting to Roslyn Coffee regulars.
- **📋 Interactive Bucket List**: Interactive checklist with celebrations.
- **📌 Digital Corkboard**: Pastel sticky notes with inside jokes.
- **💌 Realistic 3D Envelope**: Wax-sealed letter that unfolds smoothly on click.
- **🎵 Built-In Ambient Lo-Fi Synthesizer**: Procedural chime synthesizer built with Web Audio API.

## 🚀 Quick Start
Simply open `index.html` in any modern web browser!
